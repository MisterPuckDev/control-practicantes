# Sistema Control de Practicantes

## Descripción

Sistema empresarial desarrollado con Java 21 y Spring Boot para la gestión de horas de practicantes.

## Arquitectura

- Monolito Modular
- Arquitectura Hexagonal
- Java 21
- Spring Boot 3
- PostgreSQL
